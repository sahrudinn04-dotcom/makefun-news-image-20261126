Every story on the page was first reported on 26 November 2026.

## How it is made

The artwork for each panel was generated in-session, and every word on the
page was overlaid with PIL so the text stays crisp and legible — no
AI-generated text anywhere in the final image.

`main.ts` copies the finished `entry.png` (1024×1024, under 1 MiB) to the
output directory. The run is deterministic: the same bytes every time.
